# Caminos del Agua · Motion lab

Working page for the Caminos del Agua web motion tests.

- **Logo**: four animations (Corriente, Gotas, Trazo, Trazo relleno), each with Loop and Scroll modes, on three backgrounds.
- **Tarjetas · Siete Raíces**: the seven cards from Figma, in two layouts (Raíces, Río), with Loop, Scroll, Click and Hover modes. Clicking a card keeps it on the side you chose.

Open `index.html` directly in a browser, or visit the GitHub Pages site.

## Files

- `index.html`: page, styles and animation code
- `assets/logo-data.js`: wordmark path data, from `LOGO FINAL.svg`
- `assets/logo-centerlines.js`: centre line of every letter, used by *Trazo relleno*
- `assets/cards-data.js`: card colours, text and icon artwork, from the Figma file *Entre aguas*
- `assets/cards/`: card back photos
- `assets/siete-raices-bg.svg`: the "Nuestra Visión: Siete Raíces" page, without the placeholders
